Challenge75 - Full Project Scaffold

This project is a minimal, import-ready Android Studio project using Kotlin + Jetpack Compose.
Android Studio may prompt to download the Gradle wrapper and required SDK components.

Steps to open:
1. Open Android Studio -> Open -> select this folder (Challenge75_Full_Project).
2. When asked, allow Android Studio to download Gradle and sync the project.
3. Build -> Run on an emulator or connected device.
